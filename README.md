# Killer Pool App

React + Vite web app plus React Native native app path.

## Local web development

- `npm install`
- `npm run dev`

## Production web build

- `npm run build`
- `npm run preview`

## React Native iOS path

- Native app project: `KillerPoolNative`
- Handoff checklist: `appstore/REACT_NATIVE_XCODE_HANDOFF.md`

## Environment variables

Create `.env` with:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
- `VITE_TIMER_ADMIN_PROFILE_IDS` (optional, comma-separated)

## App Store release docs

- `appstore/REACT_NATIVE_XCODE_HANDOFF.md`
